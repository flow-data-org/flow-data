# Flow Data

Курсы, продукты и общие шаблоны для работы с данными и ИИ. Каждый проект живёт в отдельном репозитории, монорепозитория нет.

## Репозитории

| Репозиторий | Описание |
|---|---|
| [flow-data](https://github.com/flow-data-org/flow-data) | Этот репозиторий: общие правила и шаблоны |
| [.github](https://github.com/flow-data-org/.github) | Профиль организации, шаблоны Issues и PR, политика безопасности |
| course-ai-data-engineer | Курс по ИИ- и дата-инженерии. В разработке |
| product-semantic-layer | Семантический слой. Планируется |

Курсы называются `course-*`, продукты `product-*`.

## Общие правила

- [Работа с ИИ-агентами](docs/agent-workflow.md). Репозитории подключают этот документ и переопределяют отдельные пункты у себя.
- [Шаблон README](templates/README.template.md) для новых репозиториев.

## Участие

Issues и Pull Request принимаются в репозитории, к которому они относятся. О проблемах безопасности: [SECURITY.md](https://github.com/flow-data-org/.github/blob/main/SECURITY.md).
