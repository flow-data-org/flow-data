# Flow Data

Flow Data — открытая организация про данные и ИИ-инженерию: курсы, продукты и переиспользуемые шаблоны.

## Направления

- **Курсы** — практическое обучение дата- и ИИ-инженерии.
- **Продукты** — инструменты для работы с данными, например семантический слой.
- **Шаблоны** — заготовки для новых репозиториев и процессов.

## Репозитории

| Репозиторий | Описание | Статус |
|---|---|---|
| [course-ai-data-engineer](https://github.com/flow-data-org/course-ai-data-engineer) | Курс по ИИ- и дата-инженерии | в разработке |

## Схема именования

- `course-*` — курсы (например `course-ai-data-engineer`);
- `product-*` — продукты (например `product-semantic-layer`).

## Планируется

- `product-semantic-layer` — семантический слой для данных;
- `templates` — шаблоны репозиториев и документов.
